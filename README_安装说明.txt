小龙虾图片处理工具 - 安装说明

📋 任务：将第二张图片的颜色匹配到第一张图片

📁 已准备的文件：
1. process_images.py - 主处理脚本
2. simple_test.py - 测试脚本
3. install_and_run.bat - 一键安装运行脚本
4. check_simple.bat - 环境检查脚本
5. STEP_BY_STEP_GUIDE.md - 详细指南

🚀 安装步骤：

第1步：安装Python
1. 下载Python：https://www.python.org/downloads/
2. 运行安装程序
3. 务必勾选：Add Python to PATH
4. 完成安装

第2步：运行处理脚本
1. 打开CMD或PowerShell
2. 进入工作空间：
   cd C:\Users\Administrator\clawd
3. 运行一键脚本：
   install_and_run.bat

第3步：查看结果
1. 处理结果将保存为：小龙虾处理结果.png
2. 如果失败，会生成错误日志

🔧 备选方案：
如果Python安装失败，可以使用在线工具：
1. 访问：https://www.photopea.com/
2. 上传两张图片
3. 图像→调整→匹配颜色

💡 提示：
- 安装Python时一定要勾选"Add Python to PATH"
- 安装后可能需要重启命令行窗口
- 如果遇到问题，运行 check_simple.bat 检查环境
